# Domain Terminology & Glossary — ASI Theoretical Corrigibility & Containment Studio

This glossary provides authoritative mathematical and algorithmic definitions for all concepts utilized across `tp-asi-alignment-control`.

---

### Corrigibility
Property of an artificial agent that is cooperative with human attempts to correct, modify, or shut down the agent without resistance or manipulation.

### Instrumental Convergence
Thesis by Nick Bostrom that sufficiently intelligent agents pursuing diverse terminal goals will naturally pursue convergent intermediate subgoals (e.g., self-preservation, resource acquisition).

### Mesa-Optimization
Phenomenon where a machine learning system trained by an outer optimization algorithm itself generates an inner optimizer pursuing a different sub-objective.
